# ✨ Dreamlight Guide

Inoffizielle Android-Nachschlage-App für **Disney Dreamlight Valley** mit allen Add-ons
(A Rift in Time, The Storybook Vale, Wishblossom Ranch, Honeyglow Woods, The Keepsake Sea).

- 🔍 Suche im kompletten Dreamlight Valley Wiki – auch mit deutschen Begriffen
- 🇩🇪 Automatische Übersetzung der Wiki-Texte auf dem Handy (Google ML Kit, offline nach einmaligem Download)
- 📜 Missionen mit Ablauf und Zielen zum Abhaken
- 🔗 „Wo kommt das vor?“ – Zusammenhänge zwischen Gegenständen, Figuren, Missionen und Rezepten
- ⭐ Merkliste, Verlauf, Offline-Speicher
- Maskottchen Funkel, Mumi, Wolki & Sprössi (eigene Figuren)

## APK bekommen
Jeder Push auf `main` baut per GitHub Actions eine neue APK.
Download: **Releases** (rechts auf der Repo-Seite) → `DreamlightGuide.apk`.
